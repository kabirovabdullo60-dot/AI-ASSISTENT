# Роҳнамои код (вебсайт, Abdullo)

Ин файл кодро тағйир намедиҳад. Он танҳо нишон медиҳад, ки **кадом файл чӣ кор мекунад** ва ҷавоби ҳар савол дар кадом файл аст. Ҳамаи код дар папкаи `lib/` ҷойгир аст.

---

## 1. Сохтор бо 1 ҷумла (MVVM)

> **Экран (View) → Мағзи экран (ViewModel) → Хизмат (Service) → Сервер (API-и Mehroj)**

| Папка | Бо забони одӣ | Мисол |
|---|---|---|
| `views/` | **Экранҳо**: он чи корбар мебинад | `dashboard_view.dart`, панели асосӣ |
| `viewmodels/` | **Мағзи экран**: маълумотро нигоҳ медорад ва ба кадом тугма чӣ шавад, муайян мекунад | `dashboard_view_model.dart` |
| `services/` | **Хизматҳо**: ба сервер дархост мефиристанд | `sales_service.dart`, фурӯш |
| `models/` | **Қолабҳои маълумот**: JSON-и серверро ба объекти Dart табдил медиҳанд | `sale_model.dart` |
| `widgets/` | **Қисмҳои хурди такроршаванда**: корт, тугма, ҷадвал | `kpi_card.dart` |
| `core/` | **Танзимоти умумӣ**: рангҳо, шрифт, суроғаи сервер, тарҷума | `app_colors.dart` |
| `l10n/` | **Тарҷумаҳо** (тоҷикӣ, русӣ, англисӣ) | `app_tg.arb` |

## 3. Як амал аз аввал то охир: "Сабти фурӯш"

1. Корбар тугмаи **"Сабти фурӯш"**-ро пахш мекунад: `views/dashboard_view.dart` (`_HeroCard`)
2. Тирезача кушода мешавад: `views/record_sale_dialog.dart`
3. "Сабт"-ро пахш мекунад, ва мағзи экран кор мекунад: `viewmodels/sales_view_model.dart`
4. Хизмат ба сервер мефиристад: `services/sales_service.dart` → `POST /api/sales`
5. `core/network/api_client.dart` token-ро илова карда, дархостро мефиристад.
6. Сервер ҷавоб медиҳад, ва `models/sale_model.dart` онро ба объект табдил медиҳад.
7. Экран навсозӣ мешавад, ва дашборд рақами навро нишон медиҳад.

**Ҳамаи амалҳои дигар ҳам ҳамин роҳро мегузаранд.**
